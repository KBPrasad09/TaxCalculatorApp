# 🧮 Tax Calculator App

A modern, responsive Tax Calculator web application built with React, Vite, and Tailwind CSS. Easily calculate your income tax based on your earnings and get a clear breakdown of your tax liability.

## 🚀 Live Demo

[View Live on Vercel](https://your-vercel-url.vercel.app)

## ✨ Features

- 💰 Calculate income tax instantly
- 📊 Clear breakdown of tax amounts
- 📱 Fully responsive design (mobile & desktop)
- ⚡ Fast and lightweight (powered by Vite)
- 🎨 Clean UI styled with Tailwind CSS

## 🔧 Getting Started

### Prerequisites
- Node.js (v16 or above)
- npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/KBPrasad09/TaxCalculatorApp.git
```

2. Navigate to the app directory:
```bash
cd TaxCalculatorApp/TaxCalculatorApp
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open your browser and visit `http://localhost:5173`

## 📦 Build for Production

```bash
npm run build
```

## 🌐 Deployment

This app is deployed on **Vercel**. Any push to the `main` branch triggers an automatic deployment.
